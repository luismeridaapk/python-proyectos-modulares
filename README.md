## 🚀 Proyectos Destacados

### 💼 E-Commerce & Multi-Branch Inventory Manager (`MODULO 5`)
* **Descripción:** Sistema CLI para la consolidación de stock multi-sede en tiempo real.
* **Características:**
  * Uso de conjuntos (`sets`) para detectar SKUs duplicados e identificar productos exclusivos por región.
  * Agregación automática de stock y valorización monetaria de catálogo en $O(1)$.

### 👤 User Profile Generator & Inventory Engine (`MODULO 6`)
* **Descripción:** Suite de funciones parametrizadas y modularizadas para la creación de perfiles de usuario y gestión de inventario en memoria.
* **Características:**
  * Retorno de tuplas de validación `(bool, mensaje)`.
  * Procesamiento dinámico de datos extra con `**kwargs`.
  * Normalización de cadenas y control de ciclo mediante menús interactivos.
